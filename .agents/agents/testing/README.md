# Agents - Testing

Skills for software testing agents.

- `testing-agent/` - role skill: how a testing agent operates. Owns
  independent verification; derives tests from acceptance criteria and
  reports coverage gaps honestly.
- Workflow skills it composes live under `skills/testing/` (unit, 
  integration, end-to-end).

Add further skills as subdirectories, one `SKILL.md` per skill.
